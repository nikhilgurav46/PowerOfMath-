# ⚡ Power of Math – AWS Cloud Project

A simple web-based mathematical power calculator built using **Amazon Web Services (AWS)**. The application takes a base number and an exponent, calculates the result, and can store calculation records in Amazon DynamoDB.

This project is inspired by the AWS project tutorial referenced below.

## 📌 Project Overview

The Power of Math application allows users to calculate the power of a number using the formula:

\[
\text{Result} = \text{Base}^{\text{Exponent}}
\]

For example, if the base is `2` and the exponent is `3`, the result is `8`.

The project demonstrates how a web frontend can communicate with AWS cloud services to process user input and store calculation data.

## 🎯 Objectives

- Build a simple and user-friendly calculator interface.
- Use AWS Lambda to process mathematical calculations.
- Connect the frontend to a backend through Amazon API Gateway.
- Store calculation records using Amazon DynamoDB.
- Host the frontend using AWS Amplify.
- Understand cloud application architecture and serverless computing.

## 🛠️ Technologies Used

- **AWS Amplify** – Frontend hosting and deployment
- **Amazon API Gateway** – API endpoint for frontend-backend communication
- **AWS Lambda** – Serverless backend computation
- **Amazon DynamoDB** – NoSQL database for calculation records
- **AWS IAM** – Permissions and access management
- **Python** – Backend calculation logic
- **HTML, CSS and JavaScript** – Frontend interface
- **Boto3** – AWS SDK for Python

## 🏗️ Architecture

The application follows a serverless architecture:

1. The user enters a base number and exponent in the web interface.
2. The frontend sends a request to the API Gateway endpoint.
3. API Gateway invokes the AWS Lambda function.
4. Lambda calculates the power of the given number.
5. The result can be stored in DynamoDB.
6. The result is returned to the frontend and displayed to the user.

**Architecture flow:**

`User → AWS Amplify (Frontend) → API Gateway → AWS Lambda → DynamoDB`

## ⚙️ AWS Services Configuration

### 1. AWS Amplify
Used to host and deploy the frontend application.

### 2. Amazon API Gateway
Provides an HTTP endpoint through which the frontend can send calculation requests to Lambda.

### 3. AWS Lambda
Runs the backend Python code to calculate the mathematical power.

### 4. Amazon DynamoDB
Stores calculation records generated by the application.

### 5. AWS IAM
Manages the permissions required for AWS services to communicate securely.

## 🚀 Deployment Overview

To deploy the application:

1. Create an AWS Lambda function using Python.
2. Configure the function to calculate the power of the supplied base and exponent.
3. Create a DynamoDB table and configure the Lambda execution role with the required permissions.
4. Create an API Gateway endpoint and integrate it with the Lambda function.
5. Configure CORS if the frontend and API use different origins.
6. Add the API Gateway endpoint to the frontend configuration.
7. Deploy the frontend using AWS Amplify.
8. Test the application with different base and exponent values.

**Important:** Update the frontend with your actual API Gateway URL and ensure that the Lambda function, DynamoDB table, IAM permissions, request format, and database key schema match your AWS configuration.
